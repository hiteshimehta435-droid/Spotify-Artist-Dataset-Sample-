## 📌 Dataset Columns

* **Artist Name** – Name of the artist.
* **Genre** – Primary music genre.
* **Monthly Listeners** – Spotify monthly listeners (in millions).
* **Followers** – Spotify followers (in millions).
* **Total Streams** – Total Spotify streams (in billions).
* **Top Song** – Artist's most popular track.
* **Country** – Artist's home country.

> **Note:** This is a sample dataset created for educational purposes and README demonstrations. The values are illustrative and may not reflect current Spotify statistics.
