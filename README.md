# 🎵 Spotify Artist Dataset (Sample)

## 📌 Overview

The **Spotify Artist Dataset (Sample)** is a sample dataset created for educational purposes. It contains information about popular Spotify artists, including their followers, popularity score, genres, monthly listeners, country, and debut year.

This dataset is useful for beginners who want to practice **Python, Pandas, NumPy, Data Analysis, Data Visualization, Machine Learning, and SQL**.

---

## 📂 Dataset Information

**File Name:** `spotify_artist_dataset.csv`

### Dataset Columns

| Column            | Description                      |
| ----------------- | -------------------------------- |
| Artist_ID         | Unique ID of the artist          |
| Artist_Name       | Name of the artist               |
| Followers         | Total Spotify followers          |
| Popularity        | Spotify popularity score (0–100) |
| Genres            | Music genre                      |
| Monthly_Listeners | Monthly listeners                |
| Artist_Type       | Solo / Band / Group              |
| Country           | Artist's country                 |
| Debut_Year        | Year of debut                    |
